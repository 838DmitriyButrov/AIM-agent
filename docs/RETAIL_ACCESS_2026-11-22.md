## Журнал изменений

- У бенчмарка появились `--site` (можно повторять) и `--max-pages` (1–50). По умолчанию три сайта и три страницы на сайт. Один бюджет используется и при запуске, и в журнале.
- При нуле HTML-страниц отчёт сохраняет число деклараций sitemap, результат проверки XML по стандартному адресу и её HTTP-статус. Значение `unknown` обозначает отсутствие соответствующего результата. При этом сохраняются `blocked_http` и пустой список находок.
- Добавлены регрессионные тесты на стандартный и расширенный бюджет, ошибочный лимит и метаданные sitemap при 401. Сетевые вызовы в этих тестах подменены контролируемыми ответами.

## Согласованный контроль

1. МЕТРО: запустить отдельно `python -m siteaudit.benchmark --site metro --max-pages 12` из согласованной среды. Сравнить `sampled_pages`, `max_pages_requested` и `crawl_limit_reached`. Двенадцать — верхний предел выборки.
2. Для «Ленты» и «Ашана» передать владельцу UTC запроса, хост и путь, User-Agent `SiteAuditAgents`, код 401 и исходящий IP согласованного запуска. Попросить сверить с журналами CDN/WAF и приложения, определить компонент и правило. В разрешённой среде повторить один GET с тем же клиентом и зафиксировать итоговый URL, код, безопасно обработанную схему авторизации и разрешённый идентификатор запроса. Сырой заголовок, секреты и тело отказа в отчёт не включать.
3. Для регулярного аудита согласовать staging либо allowlist фиксированного исходящего IP с владельцем. Зафиксировать хосты, допустимые пути, время и частоту. При официальной авторизации использовать `SITEAUDIT_AUTH_HOST` и `SITEAUDIT_AUTH` только для согласованного HTTPS-хоста. После успешного HTTP-доступа использовать опциональный Playwright для проверки JS на разрешённом хосте в изолированной сети. При 401, 403 или challenge остановить соответствующую проверку.
4. С публичных карт сайта можно получить перечень URL. Из подтверждённого ресурса Google Search Console и Яндекс Вебмастера владелец может предоставить выгрузки с состоянием индексации и данными обхода. В отчёте сохранять источник и дату. Для проверок разметки, форм и документов необходимы доступные страницы и отдельная проверка применимости. Видимость в ИИ-ответах этим способом не измеряется.
