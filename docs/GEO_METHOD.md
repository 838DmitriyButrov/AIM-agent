# GEO/SEO Agent — методика v0.2, AI Search first

**Цель:** выявить технические барьеры и темы для содержательного улучшения поисковой пригодности сайта. **Не** предсказывать цитируемость или позиции.

1. **Доступ:** robots.txt (Googlebot, YandexBot, OAI-SearchBot, Claude-SearchBot и PerplexityBot), HTTP/X-Robots-Tag, meta robots и отдельные теги для ботов, ограничения на snippets, canonical. `robots.txt` — механизм crawl control, а не гарантия деиндексации.
2. **Содержимое:** title, заголовки, признаки пустого initial HTML, сравнение с DOM после рендеринга при опциональном Playwright. Краткость текста без контекста не считаем ошибкой.
3. **Карта сайта:** отличать HTTP 200 HTML от XML sitemap, учитывать нестандартный URL в `Sitemap:`; содержимое объявленных карт пока не верифицируется.
4. **Структурированные данные:** отмечать синтаксические ошибки JSON-LD и перечислять фактически объявленные типы, включая вложенные сущности. Пригодность для поисковых функций оценивается с учётом назначения страницы.
5. **Соответствие запросам:** только явно заданные целевые вопросы. Детерминированный лексический ноль = низкоуверенное `needs_review`, а не SEO-вердикт; смысловую глубину можно оценивать LLM с ручной верификацией.
6. **Фактическая AI-видимость:** `not_tested`, пока не подключены официальные отчёты или контролируемые внешние измерения. Отчёт Яндекс Вебмастера по Алисе AI требует подтверждённых прав.

## Сравнение с фактической выдачей

Для каждого запроса агент сопоставляет заголовок и текст органического результата с `title` и `meta description` HTML того же URL. Рядом показывает поисковик, запрос, регион, дату, источник и номер результата в снимке. Различия требуют оценки по намерению запроса. По одному снимку нельзя установить влияние на кликабельность, изменение позиций или причину, по которой поисковик показал другой текст.

### Яндекс Search API

Доступ настраивается через переменные окружения `YANDEX_SEARCH_API_KEY` и `YANDEX_SEARCH_FOLDER_ID`. Запросы отправляются в официальный API по явному флагу, до пяти запросов за запуск и до десяти результатов на запрос. Регион 213 соответствует Москве. XML содержит заголовки и фрагменты, которые могут отличаться от сниппета в обычном интерфейсе Яндекса.

```bash
siteaudit scan https://example.org/ --agent geo --max-pages 12 \
  --yandex-serp --serp-region 213 --query 'пример целевого запроса'
```

### Снимок выдачи Google или Яндекса

Передайте файл с фактически наблюдавшимися органическими результатами. Пример структуры с условными данными:

```json
[
  {
    "engine": "Google",
    "query": "пример целевого запроса",
    "region": "Москва, десктоп",
    "observed_at": "2026-11-22T12:00:00+03:00",
    "source": "Ручной снимок Google Search",
    "results": [{"url": "https://example.org/", "position": 3, "title": "Заголовок в выдаче", "snippet": "Текст результата"}]
  }
]
```

```bash
siteaudit scan https://example.org/ --agent geo --serp-file serp.json
```

После успешной загрузки стартовой страницы агент приоритетно проверяет URL из выдачи в пределах того же источника и бюджета. Правила robots.txt применяются как при обычном обходе. Выборка обхода и снимок могут содержать разные адреса. Если совпадающего URL с доступным HTML нет, сравнение по этому запросу помечается как непроверенное. Search Console Search Analytics подходит для показов, кликов и средней позиции. Текст отображавшегося заголовка или сниппета из него получить нельзя. Цитирования в ИИ-ответах проверяются отдельно.

- [Заголовки в Google Search](https://developers.google.com/search/docs/appearance/title-link)
- [Сниппеты в Google Search](https://developers.google.com/search/docs/appearance/snippet)
- [Google Search Analytics API](https://developers.google.com/webmaster-tools/v1/searchanalytics/query)

## Лучшие практики

- У Google нет особой обязательной schema.org/`llms.txt` для AI Overviews или AI Mode. Применяйте общие принципы поисковой доступности, полезности и достоверности информации.
- У Яндекса ответы Алисы AI связаны с качеством обычных результатов поиска; доля цитирований SoV зависит от набора запросов и периода.
- Не подменять редактуру контента массовой генерацией бесполезных текстов и фиктивных E-E-A-T маркеров.
