# Изменения

## v0.2.0 — 22.11.2026

По результатам шести аналитических проходов по рынку SEO/compliance-аудита, первичным юридическим источникам, документации Google/Яндекса и OWASP:

- LEGAL: привязка политики к страницам сбора данных, отличия непроверенного документа от отсутствующего, контекст для обработки ПДн, исключение универсальных ручных задач для сайтов без релевантных признаков.
- GEO/SEO: X-Robots-Tag, bot-specific meta robots, robots.txt для Googlebot/YandexBot, ограничения сниппетов, XML sitemap и `Sitemap:`, сопоставление с клиентскими запросами, сравнение initial HTML с rendered DOM.
- Снятие шумных эвристик «нет JSON-LD — проблема GEO» и «меньше 80 слов — плохая страница».
- Типы: `applicability`, `evidence_level`, SHA-256 статического HTML, стабильные идентификаторы проблем, охват сканирования.
- Краулер: дополнительное ограничение попыток и очереди, запрет известных потенциально state-changing GET путей, чтение HTTP заголовков.
- Упаковка: включение JSON-реестра правил в wheel.
- 29 тестов, включая HTTPX MockTransport и сценарии, специально направленные на ложные срабатывания.

**Не следует интерпретировать рост числа тестов как доказанный прирост точности на реальном рынке.**

Судебная практика и production SSRF protection остаются отдельными незавершёнными задачами.
