# Изменения

## v0.2.4 — 22.11.2026

Результат повторного технического аудита шести подсистем и сопоставления с рынком:

- **Crawler:** собственный RFC 9309 robots product-token `SiteAuditAgents` вместо браузерного User-Agent; сохранены безопасные параметры категорий, фильтров, сортировки, SKU и пагинации; исключена декларация `br` без декодера.
- **Credential isolation:** Bearer/Basic из переменной `SITEAUDIT_AUTH` отправляется только для HTML по точному `SITEAUDIT_AUTH_HOST`, не отправляется в robots/sitemap, не наследуется при переходе на соседний хост.
- **GEO:** scope-specific названия роботов в объяснении `noindex`/ `nosnippet`; исправлена обработка `max-snippet:0`.
- **Отчёты:** статусы `not_tested` вынесены в отдельный раздел; полный запрет обхода через robots теперь `blocked_robots`, а не ложный дефект сайта.
- **Private API:** ограничение до одной проверки одновременно на процесс, 429 при занятости, валидный отказ на некорректный порт.
- **Quality gates:** новые pytest-регрессии; матрица четырёх независимых полных прогонов на Python 3.11, 3.12 (два независимых запуска), 3.13; compileall и pip check.
- **Документация:** изменения, результаты CI, известные пробелы и план следующих этапов в `docs/IMPLEMENTATION_LOG_2026-11-22.md`.

Не реализованы и не следует объявлять закрытыми: сетевая защита от SSRF на уровне реального соединения, юридически верифицированный реестр, owner-verified evidence store, подключение Search Console/Вебмастера, полномасштабная браузерная модель, UX-агент, production RBAC/очередь задач. Текущий API остаётся приватным.

## v0.2.0 — 22.11.2026

По результатам шести аналитических проходов по рынку SEO/compliance-аудита, первичным юридическим источникам, документации Google/Яндекса и OWASP:

- LEGAL: привязка политики к страницам сбора данных, отличия непроверенного документа от отсутствующего, контекст для обработки ПДн, исключение универсальных ручных задач для сайтов без релевантных признаков.
- GEO/SEO: X-Robots-Tag, bot-specific meta robots, robots.txt для Googlebot/YandexBot, ограничения сниппетов, XML sitemap и `Sitemap:`, сопоставление с клиентскими запросами, сравнение initial HTML с rendered DOM.
- Снятие шумных эвристик «нет JSON-LD — проблема GEO» и «меньше 80 слов — плохая страница».
- Типы: `applicability`, `evidence_level`, SHA-256 статического HTML, стабильные идентификаторы проблем, охват сканирования.
- Краулер: дополнительное ограничение попыток и очереди, запрет известных потенциально state-changing GET путей, чтение HTTP заголовков.
- Упаковка: включение JSON-реестра правил в wheel.
- 29 тестов, включая HTTPX MockTransport и сценарии, специально направленные на ложные срабатывания.

**Не следует интерпретировать рост числа тестов как доказанный прирост точности на реальном рынке.**

Судебная практика и production SSRF protection остаются отдельными незавершёнными задачами.
