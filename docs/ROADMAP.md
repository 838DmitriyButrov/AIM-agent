# План развития после v0.2

## P0 — до любых коммерческих сканирований

1. Развёртывание в отдельной сетевой среде: обязательная аутентификация, egress filtering после DNS resolution и DNS-pinning, квоты/очереди, сканирование только разрешённых клиентом сайтов. **Текущий API не публиковать.**
2. Экспертная верификация нормативного реестра для коммерческого применения; проверенные судебные акты с номером, датой, ссылкой и точным выводом. Ни одной выдуманной судебной практики.
3. Интеграционные тесты на собственном контролируемом сайте с разными формами, редиректами, JS и состояниями cookies. Проверять согласие/отказ только с разрешением владельца, не отправляя ПДн.
4. Устойчивое хранение захваченных доказательств с журналом, сроком хранения и механизмом маскирования ПДн; доказательная ссылка на HTML hash сама по себе не заменяет сохранённый материал.

## P1 — экспертная ценность

1. Оценка качества самой политики и договорных документов (ручная валидация LLM-выводов).
2. GEO: импорт подтверждённых данных Яндекс Вебмастера по видимости в Алисе AI, Google Search Console; мониторинг фиксированного набора запросов.
3. Семантический query-to-page mapping + интенты, фактическая полезность страницы, проверка достоверности и актуальности сведений.
4. Template clustering, группировка дубликатов, приоритизация по типу страницы и реальным метрикам, повторные аудиты и diff проблем.

## P2 — развитие платформы

1. Уполномоченные безопасные browser journeys на тестовых аккаунтах, состояние `before/after/reject`.
2. UI для юриста и SEO-специалиста, решение по каждой находке, handoff в задачи разработки.
3. UX/UI агент как третий независимый модуль поверх общей модели доказательств.
