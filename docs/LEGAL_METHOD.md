# LEGAL Agent — методика v0.2

**РФ; предварительный реестр:** `src/siteaudit/data/legal_rules.json`, контрольная копия `config/legal_rules.json`. Дата проверки публичных формулировок: 22.11.2026. Юрист должен актуализировать юридические условия, исключения и судебную практику перед коммерческой публикацией.

## Конвейер

1. Определить применимость: российская аудитория, оператор данных, форма сбора, B2C/B2B, подписки, реклама, платежи, отрасль. Большая часть характеристик требует информации владельца.
2. Собрать только наблюдаемые факты: поля форм, тексты чекбоксов, ссылки на политику **на странице сбора**, заявленные документы.
3. Сопоставить сигнал с нормой из версионированного реестра. Сигнал не равен нарушению; сохранять `applicability`, `evidence_level`, `status`.
4. Проверить доказательную достаточность: ссылка на документ ≠ прочитанный документ. Временное отсутствие ссылки в HTML ≠ отсутствие после JS-рендеринга. Наличие checkbox ≠ подтверждение полученного законного согласия.
5. Направить спорный случай юристу. Не присваивать автоматически статусы `passed` или «подтверждено нарушение» без соответствующего протокола.

## Реально реализовано

- Формы, вероятно собирающие ПДн: наличие ссылки на политику на странице; непроверенный URL отмечается `not_tested`.
- Предварительно отмеченное согласие: наблюдение `potential_risk`, только когда форма вероятно собирает ПДн и содержание checkbox указывает на согласие. Дополнительно выделяется объединённое подтверждение оферты/рассылок.
- Возможный B2C-сценарий и отсутствие типовых сведений о продавце в просмотренной выборке: `needs_review`, низкая уверенность.
- Условные ручные проверки локализации, безопасности, регистрации в РКН, ККТ, рекламы и языка активируются по признакам применимости; не навязываются каждому информационному сайту.

## Реально НЕ проверено

- Правовое основание обработки, полный текст и юридическая достаточность политики, действительность полученного согласия.
- Договоры с обработчиками, локализация баз, меры защиты, регистрация в РКН, фактические чеки и маркировка рекламы.
- Судебная практика. `case_law: []` намеренно пусты — реальные дела можно добавлять только после проверки судебного акта, реквизитов и применимого периода.
