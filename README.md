# AIM Agent — Site Audit Agents

Система независимых агентов аудита сайтов: LEGAL, GEO/SEO и запланированный UX/UI.

Первая версия содержит LEGAL (предварительная проверка по российскому законодательству) и GEO/SEO (проверка технической доступности страниц для поиска и ИИ-систем).

> Результаты носят предварительный характер и не являются юридическим заключением или гарантией присутствия в ИИ-ответах.

Исходная реализация — Python 3.12; развёртывание предусмотрено в Railway.
